# Homework 8: Вынос системы диалогов в отдельный сервис

## Архитектура

Система диалогов вынесена из монолита `socialnetwork` в отдельный сервис `chat`. Монолит сохраняет обратную совместимость — `/dialog/*` проксируется без изменения контракта для старых клиентов.

### Сервисы

| Сервис            | Описание                                     | Порт |
| ----------------- | -------------------------------------------- | ---- |
| socialnetwork     | Монолит (пользователи, посты, лента, друзья) | 8000 |
| chat              | Сервис диалогов                              | 8001 |
| wsnotifier        | WebSocket push-уведомления                   | 8002 |
| postgres          | PostgreSQL 14 — основная БД монолита         | 5432 |
| citus-coordinator | Citus 13 — шардированная БД для диалогов     | 5433 |

### Поток запроса диалога

```
Старый клиент → Monolith :8000/dialog/* → ReverseProxy → Chat :8001
Новый клиент  →                                          Chat :8001
```

Каждый сервис считывает входящий `X-Request-Id`, если заголовок не найден, то генерирует новый UUID и добавляет логирование `request_id` в каждой записи. 

В каждом ответе отдается полученный/новый `X-Request-Id`.

Монолит не валидирует схему dialog-запросов и токен (`Authorization`). В сервис `chat` передается полученный/новый заголовок `X-Request-Id`.

## Как запустить

### 1. Поднять окружение

```bash
make up
```

### 2. Запустить приложения

```bash
make run 
```

### 3. Postman

В корне проекта есть коллекция Postman.
- Зарегистрируйте двух пользователей.
- Залогиньтесь одним из них.
- Отправьте сообщения сначала через порт 8000 (монолит), потом через порт 8001 (сервис chat).
